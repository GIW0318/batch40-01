# GSB Bugfix Task
## 题面
大场景重新烘焙以后，墙面出现黑线，小物件干脆没有光照。UV 岛的留边按固定像素给，图集分辨率一提高就不够，相邻岛的颜色渗过来。图集尺寸不是二的幂时，最后一块被裁掉，那片区域采样到空白。旋转摆放的岛包围盒算错，两个物体重叠在一起，光斑互相串。不同大小的物体共用同一个光照贴图密度，近处桌面糊成一片，远处大楼反而过采样。接缝处的 UV 没有对齐到纹素中心，墙角出现一条黑缝。图集从二〇四八扩到四〇九六以后，旧的引用没有重映射，物体采样到别人的岛。打包顺序依赖文件系统遍历，同一批资源两次烘焙出来的布局不同，增量更新全乱。图集超过显卡上限时整张退回单色，没有任何提示。烘焙线程上传纹理和渲染线程采样并发，偶尔读到半张图。面积太小的岛被直接丢弃，桌上的杯子没有影子。透明材质的岛也占空间，白白浪费一半图集。想要的是留边随分辨率缩放、非二的幂和旋转岛不重叠、接缝纹素对齐、扩容后引用完整重映射、打包结果可复现，超限和图集耗尽要有明确降级。这 15 条用例当前全数失败，整片红。

## 运行方式
```bash
python -m pytest tests -q
```
