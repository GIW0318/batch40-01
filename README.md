# GSB Bugfix Task
## 题面
音频中台批量归一响度之后，语音包一会儿震耳、一会儿听不清。积分响度没有做门限，长段静音把整体拉低，归一时给了过大的增益。真峰值按采样点算，没做过采样，几首电子乐直接削顶。多声道素材把各声道直接相加，五点一版本比立体声版本响一截，低频效果声道还被重复计权。不到一个积分窗口的短音效结果乱跳，同一批文件两次跑出来不一样。已经是目标响度的文件又被加了一次增益，越归一越响。采样率不同的文件按固定样本数切窗口，短文件偏差明显。写回的时候把原有的标签和封面弄丢了，发行那边要重新补。批量并发写同一个输出目录，同名文件互相覆盖。目标响度是负数时符号处理错，变成正增益。纯静音文件被归一成满幅底噪。专辑模式和单曲模式混着用，同一首歌两个版本响度对不上。批量任务没有断点记录，跑到一半失败只能整批重来。归一化这块要积分门限和真峰值检测都可靠、多声道按正确权重计算、短素材有稳定策略、已达标文件不重复增益、元数据完整保留、并发输出不打架，整批处理也要能算清耗时。这 15 条用例当前一律失败，全红。

## 运行方式
```bash
python -m pytest tests -q
```
