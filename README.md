# GSB Bugfix Task
## 题面
会员站的免密登录被投诉异地登录，安全同学把换发日志拉出来，发现整条链路只有一半是新的。旧凭据换出新值以后没有作废，拿旧值还能继续换，直到自然到期；一张凭据被拷到第二台机器，两台同时换发，各拿到一份新值，从此两条链互不相干；链的编号是自增的，看到自己的一号就能推测别人的；注销时只删了浏览器本地那份记录，服务端存的那一条原样还在；用户改密之后，老凭据照旧能登；库里存的是明文，运维导一份数据就能登任意账号；设备信息没有参与校验，值拷走就能用；多个页面同时换发，会互相把对方顶下线；续期只有滑动一种，没有最长寿命，一张值能续一年；编号冲突时后写覆盖先写，跨账号也能命中。persistent_login_family.py 的 PersistentLoginFamily 要把整条链管住：每次换发作废旧值，旧值再次出现按盗用处理并吊销全链，链的标识要高熵，并且和用户绑死，注销和改密按用户把整条链清掉，凭据只存摘要并用常量时间比较，设备信息参与校验，多页面给一个很短的过渡期，不要一上来就吊销，滑动期和最长寿命同时生效，快照里不出现凭据原文。十五项检查挂在那里，从昨天到现在一直红着。

## 运行方式
```bash
python -m pytest tests -q
```
