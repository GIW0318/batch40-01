# GSB Bugfix Task
## 题面
一次例行更新之后，公会频道里为了任务记录吵了半小时，两拨人各自贴了任务日志截图。把任务共享给已经通关的人，对方记录直接退回第一章；共享之后只有队长涨进度，队员打怪不算；相隔两张地图也能共享，确认框照样弹出来；分属两个位面的成员也能互相共享，任务目标却不在同一处；同一个共享请求重复提交，任务被接了两遍；队员放弃任务，队长的记录也跟着倒退；前置章节没做完也能共享后续内容；共享的瞬间队伍解散，任务落到上一支队伍里；日常任务共享后计数翻倍，一天能交两次；敌对阵营之间没有拦截；任务日志里出现两条同名任务，删掉一条另一条还在。quest_share_relay.py 的 QuestShareRelay 管共享、接受、进度和放弃。共享前校验阵营、位面、距离和前置；已完成或已接同一任务的人直接拒绝；记录按个人保存，队长变化不影响队员；重复请求按请求编号去重；队伍解散后共享失效；放弃只清个人进度；日常计数按周期和任务双键去重。共享请求带过期时间，队伍状态变化后旧请求作废；接受时重新校验前置和位面；队员自己的计数要能单独查；任务日志按编号去重，显示个人进度和共享来源。tests/test_quest_share_relay.py 那十五项我一早跑到现在，还是全挂。

## 运行方式
```bash
python -m pytest tests -q
```
