# GSB Bugfix Task
## 题面
公会招募板改版后，会长和官员天天吵架。同一个玩家重复提交申请，列表里出现五条一模一样的记录；申请过期三天后仍然能点批准；官员批准时公会名额已满，玩家还是进来了，显示成员数超上限；申请人已经在别的公会，批准后两个公会里都能看到他；拒绝过的申请还能用旧链接再次通过；会长转让期间，审批结果记到了旧会长头上；黑名单玩家改个名字重新申请，系统认不出来；批量批准十个人只成功三个，界面却提示全部成功；申请列表按时间倒序显示，批准顺序却按编号；公会升级扩容和批准并发，最后多出两个人；申请备注里带换行，把列表解析成两条。guild_application_roster.py 的 GuildApplicationRoster 负责 apply、approve、reject 和 capacity。申请按玩家和公会唯一，重复提交只更新旧记录；过期申请自动拒绝；批准时在同一事务里校验名额和玩家归属；黑名单按账号而不是角色名；批量操作逐条返回结果；会长变更后审批权跟着走；备注按纯文本存。审批结果要实时推送到同一公会的所有管理端；同一申请只允许一个审批结果落地；名额统计把待批准和已入会分开，批准时再校验一次；申请状态变化要留下旧状态和操作者。tests/test_guild_application_roster.py 的十五个用例眼下全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
