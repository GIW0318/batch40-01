# GSB Bugfix Task
## 题面
技术预研的 meshlet 管线一开，远处山体和建筑就开始缺块。cluster 包围球半径按局部空间算，物体一缩放剔除就错，放大后整片消失。层级 cluster 的父包围盒没有合并子节点，父被剔掉子节点还在，画面上剩几块碎片。锥体剔除只测 cluster 中心点，边缘的 cluster 一转头就闪没。背面锥剔除没考虑单面网格，薄墙从背面看直接不见。八位顶点索引在超过二百五十六个顶点的 cluster 里回绕，三角形连到隔壁 cluster，模型拉出长条。相邻 cluster 选到不同 LOD 时没有做边界缝合，接缝处出现裂缝。每帧在主线程重建全部剔除缓冲，CPU 预算超掉，GPU 反而空闲。异步剔除用的相机矩阵和当前帧不一致，快速转头时边缘缺一块再补上。实例化 meshlet 共用 cluster 数据但变换不同，剔除结果套错实例。单个 meshlet 超过硬件限制没有拆分，驱动直接黑屏。阴影 pass 复用主视图的可见列表，影子里缺同一批块。这套剔除要包围体覆盖缩放后的实际范围、层级剔除自底向上合并、索引宽度按实际顶点数选择、LOD 接缝有缝合策略、异步剔除结果按帧对齐，构建耗时也不能失控。那 15 条用例目前条条挂红，没有例外。

## 运行方式
```bash
python -m pytest tests -q
```
