# GSB Bugfix Task
## 题面
手游里爆炸和烟尘一多，透明粒子就开始互相穿插。排序是按发射器做的，两个发射器的粒子交错在一起，火焰会突然跑到烟后面；排序键用的是粒子生成时的深度，相机一移动就不更新，绕着爆炸走一圈能看到前后关系整段翻转。大颗粒用中心点深度而不是包围盒最近点，贴脸时半个粒子被地面切掉。同一帧由多个 worker 生成的粒子，写入顺序取决于谁先完成，每次爆炸的透明层次都不一样。软粒子深度在半分辨率缓冲上采样，和地面接触的地方出现硬边。粒子池复用的时候上一轮的排序索引没清，偶尔会冒出已经死掉的幽灵粒子。相机近平面切到大粒子的中心，整颗粒子直接不画。索引是十六位的，粒子数一多高编号的索引回绕，画到别的发射器位置上。多线程往排序缓冲写没有同步，低概率出现花屏。排序总耗时没有预算，低端机为了保帧率直接跳过排序，结果更乱。透明粒子还写了深度，后面的粒子被提前剔掉，烟看起来像被刀切过。这块的底线是排序按全局粒子做、深度每帧跟随相机更新、并行生成结果可确定复现、池复用不残留旧状态，排序开销也要有上限。15 条用例跑完，红灯从头亮到尾。

