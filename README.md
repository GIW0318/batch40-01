# GSB Bugfix Task
## 题面
新赛季开服后的第一小时，值班室桌上的电话基本没停过，问题大致能分成三类。第一类是奖励：结算脚本被重跑了一次，同一批账号收到两份赛季奖励；发放读的是当前段位，赛季最高段位那一档被忽略，掉分的人少拿一大截；奖励邮件的截止日按开服那一刻加七天，有人隔周才登上来，附件已经过期；封禁名单没有在发放前过滤，榜上的违规账号照样收到邮件。第二类是重置：软重置公式把大师直接压成青铜；定级赛没打完的账号也被重置，之前进度全部清空；脚本执行到一半进程重启，前半段已经重置，后半段还是旧段位；跨赛季的连胜记录被带进新赛季，第一把就排到高段位。第三类是账目：排行榜快照和奖励名单对不上，榜上有名字的人没收到；旧赛季代币没有回收，还能在新赛季商店里花；同一档的领取按钮被连点，两个请求各自把奖励发了出去。season_rollover_ledger.py 的 SeasonRolloverLedger 负责制作名单、重置、发放和领取。结算只认切换前定下的那份名单，重跑时按赛季编号去重，重置公式分段可配置，未定级账号单独处理，整个过程分批提交并记录断点，邮件截止时间从实际发出那一刻算，封禁名单发放前过滤，领取按账号和档位唯一，历史段位单独归档，软重置只改当前段位，未定级账号进入待定池，奖励明细把最高段位与当前段位分开记录，代币在发放后单独回收。test_season_rollover_ledger.py 的十五项检查铺开，当前没有一项是绿的。

## 运行方式
```bash
python -m pytest tests -q
```
