# GSB Bugfix Task
## 题面
编辑器热重载最近像抽风，改一次材质，场景里一半物体变黑，偶尔整个编辑器崩掉。文件监视器对一次保存触发好几次事件，同一个资源被重复重载。依赖图只记了直接引用，材质引用的贴图换了，间接依赖的模型没刷新，还显示旧颜色。资源之间成环时递归重载直接把栈撑爆。换版本的时候渲染线程还握着旧句柄，释放后画面花屏。保存到一半的文件被读到，解析失败后资源变成空对象，场景里一片紫。引用计数在重载瞬间掉到零，正在使用的资源被卸载，下一帧访问就崩。重载顺序按文件名排，父资源先于子资源，引用指向还没准备好的对象。着色器热重载后变体缓存没失效，编译出来的还是旧程序。大模型同步重载卡住主线程十几秒，编辑器像死机。撤销恢复的是旧路径，依赖图指向已经删掉的节点。网络盘延迟导致 watcher 丢事件，改完根本没反应。热重载这块得让监视事件去抖、依赖图覆盖间接引用和环检测、换版本对渲染线程安全、半写文件不生效、重载顺序按依赖拓扑、变体缓存跟随失效，重载开销也不能阻塞编辑。这 15 条用例现在全是红的，没有例外。

## 运行方式
```bash
python -m pytest tests -q
```
