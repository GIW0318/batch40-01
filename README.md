# GSB Bugfix Task
## 题面
公会银行开放跨页存取后，几个大公会都出现了物品复制。两个官员同时点同一格，双方都取到了物品，仓库里那格还没扣；每日取用上限按操作次数算，一次取一组和取一件都算一次；官员被降权后，已经打开的面板还能继续取；成员存入的绑定物品，其他成员居然能取走；公会解散时银行里的东西直接消失，没有退回邮件；取用日志只有时间没有操作者，出事查不到人；修理资金从银行扣了两次，公会资金对不上；跨页签移动没有日志，物品凭空换页；会长给自己提权绕过上限；银行扩容后旧日志指向错误页签；离线成员的待处理取用请求在重启后仍然被执行。guild_bank_audit.py 的 GuildBankAudit 要管 deposit、withdraw、set_limit、log 和 dissolve。存取按格子加锁并校验版本；权限每次操作实时读取，不能用打开面板时的快照；上限按物品数量累计；绑定物品只能本人取；解散前把剩余物品邮寄给会长；所有变动写一条含操作者、页签、前后数量的流水；重启后未完成请求要么继续要么回滚，不能半执行。日志时间统一用服务器时间并附时区；每次存取记录物品快照和前后数量；权限变更要立即让已打开的面板失效；解散时的资产清单要单独落库，邮件发送失败可重试。tests/test_guild_bank_audit.py 的十五条检查目前全红。

## 运行方式
```bash
python -m pytest tests -q
```
