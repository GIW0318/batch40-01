# GSB Bugfix Task
## 题面
护送任务改版后，失败判定和奖励都不对。护送 NPC 被地形卡住，计时还在走，玩家守着也判失败；玩家跑远后 NPC 原地等待，倒计时却不停；多个队伍同时接同一护送，地图上刷出好几个同名 NPC；护送中玩家掉线，NPC 立刻消失，任务直接失败；检查点可以跳过，直接跑到终点也算完成；NPC 被其他玩家攻击但不还手，血量归零后任务没有失败；到达终点后重复结算，奖励发了两次；超时和完成同一秒触发，成功和失败提示同时弹出；坐骑速度太快，NPC 跟不上，队伍被判定脱离；中途加入的队员没有进度，交任务时提示未完成；放弃任务后 NPC 不消失，下一队接到一个残血 NPC。escort_objective_timer.py 的 EscortObjectiveTimer 负责 start、advance、checkpoint、complete 和 fail。护送实例按队伍唯一，NPC 绑定实例；检查点必须按顺序；玩家脱离范围进入暂停而不是失败，超时才判负；掉线给宽限，重连回到原实例；完成和失败互斥且只结算一次；放弃要回收 NPC。计时状态要持久化，重启后按已用时间继续；护送 NPC 的血量归零要触发失败，不能只停计时；检查点进度单独存，不能只看最终到达；护送实例的创建和回收要幂等，重复请求返回同一个实例；计时暂停期间不推进，恢复后从暂停点继续；护送距离按服务器坐标算。tests/test_escort_objective_timer.py 的十五条用例现在都没过。

## 运行方式
```bash
python -m pytest tests -q
```
