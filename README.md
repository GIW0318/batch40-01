# GSB Bugfix Task
## 题面
联机物理最近出现一堆怪事，低帧率下角色穿墙，暂停回来直接瞬移。累加器没有最大步数限制，卡顿一下就在一帧里补几十步，越补越卡，最后卡死。固定步长和渲染帧之间没有插值，三十帧的设备上角色一抖一抖。暂停菜单打开时累加器还在累积，恢复的瞬间把积攒的时间全跑一遍。时间缩放改成零点三以后步长没跟着缩，慢动作里物理反而变快。物理、动画和粒子各自维护累加器，三者对不上，脚和地面差半格。浮点累加误差跑一晚上之后回放对不上，服务器和客户端位置越差越远。一帧内多步的事件按系统注册顺序触发，同样的输入两次结果不同。单步时长超过最大子步，薄墙直接穿过去。断点停在物理线程后恢复，dt 巨大，第一步就炸飞到天上。渲染线程读物理状态没有快照，快速移动的物体边缘撕裂。服务器和客户端固定步长不同，位置校正来回抖。物理步进要累加器有最大子步和最大补步、渲染有插值、暂停和时间缩放有明确语义、事件顺序可复现、断点和长时运行不漂移，校正也要平滑。这 15 条用例跑出来从头红到尾，一条都没过。

## 运行方式
```bash
python -m pytest tests -q
```
