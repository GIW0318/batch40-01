# GSB Bugfix Task
## 题面
对象存储的加密密钥轮换做了三次，每次都有遗留：数据密钥用新主密钥重新包裹后，旧版本的主密钥还能解开旧包裹，而且没有停用时间；轮换任务中途失败，重启后从头再包一遍，已经处理过的对象被重复计数；一批对象里九成换了新版本，任务标记却写成全部完成；主密钥版本按编号前缀查找，版本十二会被版本一命中；轮换期间主密钥被禁用，读请求全部失败，没有回退到仍可解密的旧版本；同一个主密钥并发启动两个轮换任务，产生两个活动版本；数据密钥跨租户复用，一个租户的密钥能解另一个租户的对象；备份和搜索索引不在轮换范围内，恢复出来的还是旧版本；幂等键没有生效，重试把同一个对象包了两层；审计只记了任务开始和结束，没记每个对象的版本变化。dek_rotation_plan.py 的 DekRotationPlan 要把轮换做成可恢复的计划：按对象记录旧版本和新版本，旧版本有明确停用时间，任务断点续跑不重复处理，完成标记按实际结果汇总，版本号精确匹配，禁用主密钥前先确认没有未完成对象，同密钥轮换互斥，数据密钥按租户隔离，备份和索引纳入计划，幂等键去重，审计逐对象记录。仓库里十五条用例现在全部失败。

```bash
python -m pytest tests -q
```
