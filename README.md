# GSB Bugfix Task
## 题面
合服公告发出后，登录和社交问题一起爆了。两个同名角色合并后，一个被强制改名，但好友列表还指向旧名字，私聊全发错人；公会名冲突只改了一个，另一个公会提示已存在却建不起来；邮件在合服后一半丢失一半重复；拍卖行挂单合并时同一件物品出现两次，买家拍下后两边都扣；好友关系变成单向，A 列表里有 B，B 那边没有 A；黑名单合服后失效，被拉黑的人又能发消息；排行榜把同一个玩家算了两遍，名次整体前移；角色编号冲突，登录后进了别人的角色；合服回滚后，新创建的角色全部消失；合服期间登录的玩家，数据被旧库覆盖；两个服时间不同，邮件过期判断一边提前一边延后。realm_merge_directory.py 的 RealmMergeDirectory 负责 merge、resolve_name、migrate_social 和 rollback。角色名按服优先级保留，其余进入改名队列；公会名同样处理；邮件按原始编号迁移并去重；拍卖挂单重新分配编号；社交关系双向重建；排行榜按账号去重；整个合服在可回滚的事务里分批执行。所有跨服引用按角色编号重写，显示名从新目录解析；合服批次可暂停可续跑；回滚只撤销本批次写入，不影响合服后新产生的数据；合服期间的登录要排队或拒绝，不能读旧库。tests/test_realm_merge_directory.py 的十五条检查都没通过。

## 运行方式
```bash
python -m pytest tests -q
```
