# GSB Bugfix Task
## 题面
仓库整理功能上线后，玩家的收藏和材料开始对不上。整理时两个页签同时被移动，后一个覆盖了前一个，整页物品消失；扩容之后旧页签的索引没有迁移，物品指向空页；整理任务跑到一半，玩家放进来的新物品被当成待整理项吞掉；堆叠合并超过上限，多出来的数量直接没了；任务失败后仓库停在半整理状态，既不能取也不能放；只读页签也被整理任务移动；同一件物品被两个页签同时引用，取一次扣两份；整理后收藏标记和锁定标记丢失；相同物品每次整理顺序都不一样，玩家找不到；跨服仓库整理触发了全服锁，所有人卡住；任务重试时重复移动，物品数量翻倍。vault_compaction_job.py 的 VaultCompactionJob 负责 compact、expand、place 和 snapshot。整理以页签为单位加锁，不能跨页并发；扩容先建新页再迁索引，迁完才切换；整理期间的新放入进入待处理队列，不能丢；堆叠上限和溢出要单独返回；失败要回到整理前快照；只读和锁定物品跳过；重试按任务编号幂等。容量统计按实际占用重算并写回索引；整理任务要有明确的开始和结束版本，中途查询返回旧版本；同一账号的仓库整理不能跨服并发执行；整理前后的差异要生成可回放的操作清单。tests/test_vault_compaction_job.py 的十五条用例眼下全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
