# GSB Bugfix Task
## 题面
高光回放功能上线后，剪辑出来的片段没法看。击杀片段的起点取的是客户端上报时间，不是服务器帧时间，每次都早几秒；三杀片段里同一击杀出现两遍，时间轴还对不上；片段跨过回合边界，把上一局的画面也剪进来；慢动作片段声音和画面不同步，枪声晚半秒；同一玩家同一时刻生成两条高光，分享出去两个版本；比赛结束瞬间正在裁剪的片段直接截断，文件打不开；观战视角和玩家第一视角混在同一条片子里；存储清理把还没发布的片段删了，作者找不到；片段索引按创建时间排序，不是按比赛时间；同一场比赛并发生成片段，后写的覆盖先写的；分享链接过期后仍然能打开。match_highlight_reel.py 的 MatchHighlightReel 要管 collect、cut、publish 和 expire。片段边界以服务器事件帧为准，前后留固定缓冲；同一击杀只进一个片段；跨回合要切断；音轨按同一时间基准对齐；片段编号按比赛和事件唯一；裁剪完成前不对外发布；索引按比赛时间排序；分享链接带过期和签名。封面必须来自有效画面并带时间戳；片段生成记录输入事件范围和输出文件哈希；同一场比赛的片段发布走同一把锁；过期片段保留索引但拒绝播放，不能直接删记录。tests/test_match_highlight_reel.py 的十五条用例现在全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
