# GSB Bugfix Task
## 题面
密钥管理服务开放给各业务线自助建路径后，出现了越权读：策略里的星号能跨路径分隔符匹配，本来只给某个应用的读权限变成了整棵树；拒绝规则写在允许规则后面，实现第一条命中就返回，拒绝永远不生效；路径里的点点斜杠在拼接之后才归一，编码过的斜杠又能绕一次；策略模板里的用户变量没有展开，所有人都按空值匹配；列举和读取用了同一份权限，能列目录就能读值；尾部星号把子孙路径全放开了；大小写不同的路径命中不同策略；根路径和空路径被当成同一件事；租约撤销只删了租约记录，派生出来的动态凭据还能继续用；策略快照返回内部规则对象。secrets_path_policy.py 的 SecretsPathPolicy 要先归一请求路径再匹配：拒绝优先于允许，星号只在单段内生效，路径分隔符和编码形式统一，模板变量必须展开且有默认拒绝，列举和读取分开授权，大小写按策略声明处理，根路径单独限制，租约撤销要连带吊销派生凭据，快照返回规则摘要和命中结果。仓库里那十五条用例没有一条通过。

## 运行方式
```bash
python -m pytest tests -q
```
