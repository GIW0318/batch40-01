# GSB Bugfix Task
## 题面
赛季收官那晚，负责发奖的同学盯着后台看了半小时，前一百的名单前后变了三次。零点已经过了，还有对局在往榜上写分，冻结之后名次又挪了几位；两个人分数一样，界面显示并列，发奖却按列表顺序给了不同档位；同分的人每次刷新顺序都不一样；违规账号被移出榜单后，后面的人没有顶上来，前面空出好几个位置；合区后的榜单把同一个人算了两遍；翻到第二页时正好碰到写入，第一页出现过的人又出现一次；发奖读的是实时榜单，跟页面展示的对不上；有人申诉改分，榜单更新了，奖励没有跟着补；赛季结束那一秒提交的对局被记到了下个赛季；榜单缓存设得太久，看到的还是前一天的排名；查前一百条返回了一百零三条。season_leaderboard_freeze.py 的 SeasonLeaderboardFreeze 需要处理提交、冻结、排名和发奖。冻结之后写分一律拒绝，只留申诉通道；并列用稳定键排序并共享档位；违规移除后按原顺序补位；合区按账号去重；分页基于冻结那一刻的名单；发奖只读这份名单；对局按结束时间归属赛季。冻结榜和预热榜按赛季隔开；名单里要存名次、分数和并列键；申诉走独立通道并记录前后值；发奖结果能按冻结版本回查。tests 里那十五个用例现在全红。

## 运行方式
```bash
python -m pytest tests -q
```
