# GSB Bugfix Task
## 题面
语音开黑一进地铁就开始出鬼声。序列号是十六位的，回绕的时候比较大小写错，旧包被当成新包塞进去，声音倒着播。乱序到达的包直接丢掉，根本没有进抖动缓冲，丢包率虚高。目标延迟写死二百毫秒，网络好的时候嫌大、网络差的时候又不够。时钟漂移靠周期性丢一帧来追，十分钟后延迟越积越多。丢包补偿生成的样本数和帧长对不上，拼接处爆音。静音帧不推进时间轴，一开口恢复说话时整段快进。前向纠错恢复出来的包和稍后到达的真实包重复播放，出现双音节。迟到的包在补偿之后才到，直接插进去又重复一遍。静音检测把气声全切了，听感一顿一顿。网络线程和混音线程之间的无锁队列满了就丢整帧，没有任何统计。抖动缓冲按包数设上限而不是按播放时长，短帧编码一多就频繁溢出，自适应延迟跟着丢包统计越调越大。四十八 k 和十六 k 的流混在一起没重采样，声音变尖。语音链路要序号比较能处理回绕、乱序包有等待窗口、目标延迟能自适应、漂移补偿不靠丢帧、补偿长度严格对齐帧长、重复包能识别，队列溢出也要有可观测的降级。15 条用例目前全部为红。

## 运行方式
```bash
python -m pytest tests -q
```
