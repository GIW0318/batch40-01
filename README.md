# GSB Bugfix Task
## 题面
交易行改价上线第二天，风控模型报出一批异常成交，金额和物品对不上。买家点购买的同时卖家改价，最后按改后的高价成交；撤单和成交撞在一起，物品退回卖家，钱也退给买家，凭空多出一份；改价请求没带版本号，晚到的旧请求把新价格盖掉；同一个条目被连续买走两次，两笔都成功；改价之后税费仍按原价算，卖家少收一截；部分成交后剩余数量重新上架，价格退回到最初那一版；卖家离线时撤单提示失败，挂单却已经从列表消失；自然过期和手动撤单同时触发，退件邮件发了两封；改价次数没有上限，有人靠反复改价刷前排；成交记录里的版本和挂单实际版本不一致，对账对不上；前端缓存没失效，列表还挂着旧价格。market_listing_revision.py 的 MarketListingRevision 管上架、改价、撤单、购买和结算。每次改价留一个序号，购买请求要带上自己看到的那个序号；撤单和购买只能有一个成功；部分成交生成新的剩余条目并接上序号链；税费按成交价算一次；过期与撤单互斥，退件只发一次；改价要有冷却和次数上限。购买先锁定序号再扣款，结算认锁定的那个；序号链要能还原每次改价；同一挂单的购买按序号串行，序号落后的直接拒绝；成交和退件都带条目编号与序号。tests/test_market_listing_revision.py 的十五个用例跑下来全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
