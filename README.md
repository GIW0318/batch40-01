# GSB Bugfix Task
## 题面
运营把一周内和绑定有关的咨询整理成文档，发现帮助页写的规则和实际行为几乎对不上。装备之后绑定没有传到镶嵌的宝石，宝石拆下来还能卖；解绑卷轴对已装备物品无效，卷轴却照样被消耗；账号绑定物品邮寄之后变成可交易，收件人直接挂拍卖；转区之后绑定状态丢失，一批限定物品流进市场；一件物品被同时标成装备绑定和交易绑定，界面显示两把锁；绑定后仍能上架，成交时才失败，买家的钱已经扣了；附魔来源算错，把买家的武器绑定了；解除绑定后历史记录被清掉，查不到是谁解的；批量绑定只处理第一件，其余没变；绑定事件重复投递，绑定计数翻倍；角色删除后绑定记录还挂着，物品编号被新角色复用。item_binding_ledger.py 的 ItemBindingLedger 负责绑定、解绑、传播和交易检查。绑定类型互斥且有优先级；装备绑定沿镶嵌和附魔关系传播；解绑只对允许的物品生效，失败不消耗道具；交易检查在挂单和成交两处都做；绑定解绑写事件流水，按事件编号幂等；角色删除时清理或归档记录。账号绑定邮寄要校验收件角色属于同一账号；传播遇到已绑定物品保留更严格的类型；交易检查返回具体原因而不是布尔；流水记录触发来源和操作者。tests/test_item_binding_ledger.py 里十五条，一条都没跑绿。

## 运行方式
```bash
python -m pytest tests -q
```
