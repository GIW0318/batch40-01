# GSB Bugfix Task
## 题面
位面系统接进任务后，玩家经常找不到 NPC。进位面后任务 NPC 消失，任务明明显示可交付却点不到；两个队员在不同位面，却能在主城互相看见并组队；位面切换瞬间任务进度被重置，采集数量归零；NPC 的阶段状态按玩家保存，同一个位面里两个人看到不同的 NPC；退出位面后任务标记还残留，小地图一直闪；位面合并时重复生成 NPC，一个名字出现两个模型；任务完成后 NPC 没刷新，仍然挂着可接任务；跨位面共享任务失败但没有提示，玩家以为共享成功；位面切换和进副本并发，角色卡在加载界面；位面编号复用时带入了旧任务状态；NPC 列表查询读的是旧缓存，实际已经换位面。quest_phasing_handoff.py 的 QuestPhasingHandoff 要处理 enter_phase、leave_phase、npc_state 和 sync。位面进入和离开要在一次状态迁移里完成，任务进度跟着角色走；NPC 可见性按位面和任务阶段计算，不按玩家缓存；位面合并先去重再生成；切位面和进副本互斥；编号复用要清空旧状态；查询以服务端当前位面为准。切换失败要回到切换前的位面和任务状态；过渡场景只做加载，不承载任务逻辑；NPC 查询结果带位面编号，客户端缓存按编号失效；位面状态和任务状态一起持久化，重启后能恢复到一致快照。tests/test_quest_phasing_handoff.py 的十五条断言当前全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
