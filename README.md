# GSB Bugfix Task
## 题面
跨服战场匹配改版后，玩家投诉从排队到进本都不对劲。三排队伍被拆成三个单排，分别塞进两边；补位玩家进入已经结束的对局，进去就弹出胜利结算；同一名玩家在两个战区同时排队，居然同时进了两场；匹配分只取队长，带小号的队伍一路碾压；治疗和坦克数量不满足配置也能开赛；取消排队和匹配成功同时发生，玩家被拉进已经取消的场次；等待最久的人反而最后才被匹配；跨服延迟差异没有修正，远程玩家在近战脸上瞬移；九打十的残局仍然开赛；重复入队生成两条队列记录，取消一次只删一条；匹配成功后玩家离线，名额一直不释放。crossrealm_match_pool.py 的 CrossRealmMatchPool 要处理 enqueue、dequeue、form_match、backfill 和 status。预组队必须整体匹配，不能被拆散；匹配分按队伍加权平均而不是队长个人；职责数量按战场配置校验；取消和成局用同一把锁，只有一个结果；补位只进未结束且缺人的场次；队列去重按玩家和战区；离线超时释放名额；等待时间只作为同分段的次级排序。匹配成功后写一份不可变成局记录，队伍和玩家都从队列里原子移除；补位的候选池按职责缺口过滤；跨服延迟用最近三次探测的中位数，不用单次值；同一玩家在任意战区的活动队列只能有一个；成局记录要能按场次回查双方名单。tests/test_crossrealm_match_pool.py 的十五条断言当前全红。

## 运行方式
```bash
python -m pytest tests -q
```
