# GSB Bugfix Task
## 题面
战斗组接了新的连招状态机以后，角色经常卡在过渡姿势上。轻攻击接重攻击时，上一个过渡还没结束就被打断，退出时间从零重新算，人物永远停在抬手那一帧。归一化时间和绝对时间在两套节点里混用，长动画切短动画会瞬间跳到尾帧。同步组相位没有对齐，跑步切冲刺时脚底明显打滑，两只脚在地面上搓。过渡事件在混合两端各触发一次，一次横扫打出两段伤害。上半身遮罩没排除手指骨骼，表情层被战斗动画整层盖掉。根运动在交叉淡入期间按权重叠加，一个翻滚位移出两米多。混合时长配成零时直接除零，姿势矩阵变成 NaN，整个人消失。参数类型从布尔改成触发器以后旧片段没有重新绑定，条件永远不满足，技能放不出来。多层状态机同时往同一根骨骼写权重，最终姿势每帧抖一下。过渡过程中反复请求同一个状态，队列只进不出，内存一直涨。动画蓝图热重载后旧的过渡对象还引用着已释放的片段，切场景必崩。想要的是打断时相位和退出时间可预期、事件只触发一次、遮罩和根运动不串联放大、零时长有明确退化行为、队列有上限。现在这 15 条用例无一例外全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
