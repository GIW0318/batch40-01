# GSB Bugfix Task
## 题面
过场系统接上动态音频总线以后，切场景经常爆音或者干脆没声。重建拓扑时旧的 bus 立刻销毁，还有 voice 挂在上面，回调访问已释放节点直接崩。路由表允许成环，递归混音几层就把栈撑爆。某条支路没接到 master，声音消失，日志里却什么都没有。重建时增益从零直接跳到目标值，耳机里啪一声。快照在新拓扑上重放，send 指向已经被删掉的 bus。输出从立体声切到五点一，总线缓冲没按新声道数重建，左右声道错位。整套重建在主线程同步做，超过帧预算，画面明显一顿。pre-fader 和 post-fader 的 send 标志在重建后丢失，同一套参数听感完全不同。总线深度超过上限被静默截断，最底下的环境音全没了。音频线程推 voice 和主线程重建并发，偶尔访问到半新半旧的节点。设备切到蓝牙以后采样率变了，延迟补偿没重算，口型和声音对不上。音频这边要求重建过程对在播 voice 安全、拓扑先校验再切换、增益和 send 标志能平滑继承、声道数和采样率变化有完整迁移，重建开销不能压在主线程上。15 条用例现在无一通过，全红。

## 运行方式
```bash
python -m pytest tests -q
```
