# GSB Bugfix Task
## 题面
海外素材和手机拍摄混在一起转码以后，人脸发绿，暗部发灰，红边特别明显。BT.601 和 BT.709 的矩阵按分辨率猜，七二零的素材猜错，肤色整体偏绿。有限范围当成全范围处理，暗部被压死，亮部又过曝。四二〇采样遇到奇数宽高，最后一行一列的色度越界读，边缘出现彩条。色度位置没按 co-sited 处理，红字边缘拉出一圈红边。HDR 的 PQ 转 SDR 只做线性缩放，高光全死白。带透明通道的素材预乘和非预乘混用，半透明边缘发黑。每级转换都做一次八位取整，转三四道之后出现明显色带。SIMD 处理尾部像素时越界读，偶发整帧花屏。色域矩阵行列写反，红蓝直接互换。多线程分块转换的边界重叠或者漏块，画面出现竖条接缝。硬解输出 NV12 却按 I420 取 UV，颜色整体错位。转换链路要能从码流元数据正确推导矩阵和范围、奇数尺寸和色度位置有边界处理、HDR 转换保留高光层次、透明度语义统一、多次转码减少累积误差，分块并发也不能在接缝处出错。这 15 条用例眼下全部红灯。

## 运行方式
```bash
python -m pytest tests -q
```
