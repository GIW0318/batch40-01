# GSB Bugfix Task
## 题面
雨天赛道加了反射探头以后，路面倒影一会儿跳、一会儿裂。盒投影的视差校正符号写反了，靠近探头的车身倒影被拉得很长。两个探头重叠的区域按距离线性混合，权重在交界处突变，路面出现一条明显的直边。异步烘焙还没完成的 cubemap 就被采样，半张脸是黑的。反射相机裁剪时没排除探头自身的包围盒，倒影里能看到一个漂浮的方块。HDR cubemap 没生成 mip 链，粗糙度采样永远取最高清那层，湿滑路面看起来像镜子。探头包围盒旋转之后仍按轴对齐盒子算，斜放的走廊漏掉一整面墙的反射。多个探头权重相同时按创建顺序排序，每次进场景的混合结果都不同。探头失效直接回退天空盒，没有逐像素过渡，整块地面突然变蓝。动态探头每帧全部重烘，GPU 预算直接爆。反射通道里又渲染到同一个探头，递归几次后黑屏。移动端 cubemap 面尺寸超过上限，静默降到十六，倒影糊成马赛克。反射这块要盒投影方向正确、重叠区权重连续、未完成烘焙不参与采样、mip 和粗糙度对应、失效探头平滑降级，动态烘焙也要能分摊到多帧。15 条用例跑出来满屏红，没一条过。

## 运行方式
```bash
python -m pytest tests -q
```
