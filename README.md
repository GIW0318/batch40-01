# GSB Bugfix Task
## 题面
项目碰撞层从八组扩到四十组以后，子弹会穿怪，触发器也不触发。层掩码还是三十二位，四十组之后高位回绕，两个不相干的层突然互相碰撞。矩阵只写了上三角，A 打 B 有效、B 打 A 无效，近战和远程的表现完全相反。查询掩码和刚体掩码的与运算顺序写错，射线查询全漏。复合碰撞体的子形状没有继承层，角色身体能挡住、披风直接穿模。禁用的刚体仍然参与查询，空中有一堵看不见的墙。触发器和实体碰撞共用同一张矩阵，触发器被实体挡住，进不去副本。层重命名以后旧的序列化 ID 没有迁移，存档里的怪物全跑到默认层。运行时改层没有重建 broadphase，旧配对一直残留。层数超过上限时静默截断，末端几组全部变成同一层。查询线程和层修改并发，读到只改了一半的掩码。负的层索引和空层组没有校验，数组越界。碰撞过滤要掩码宽度能随层数扩展、矩阵对称性有明确语义、查询和刚体过滤分开、复合形状继承一致、运行时改层能正确重建配对、序列化 ID 稳定，越界输入也要有明确错误。15 条用例跑完没有一条通过，满屏红。

## 运行方式
```bash
python -m pytest tests -q
```
