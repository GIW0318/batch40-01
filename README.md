# GSB Bugfix Task
## 题面
过场动画的时间轴一加多轨道就乱套。两条 clip 在同一轨道上重叠，求值按轨道顺序覆盖，后加的 clip 被静默吞掉。循环片段到结尾时事件又触发一次，Boss 的吼叫放两遍。时间缩放改到零点五以后音频没有重采样，音画越走越偏。拖动进度条到中间时之前的一次性事件不重放，相机停在错误位置。嵌套序列的时间基没有转换，子序列整体偏移几秒。空 clip 和零长度 clip 导致除零，整条轨道直接失效。相机、灯光和角色三条轨道同时控制同一属性，最终值取决于谁先求值。两个事件卡在同一个边界上，触发顺序每次不同。编辑器预览按六十帧跑，离线渲染按二十四帧跑，粒子结果完全不一样。轨道被禁用后时间还在推进，重新启用时画面跳变。长序列用浮点秒累加，跑十几分钟后精度丢失，结尾对不上。时间轴求值得让重叠 clip 有明确优先级、循环事件只触发一次、时间缩放同时作用于音频并重采样、seek 能重建一次性事件状态、嵌套时间基正确换算、零长度有退化处理、求值顺序稳定，预览和离线结果也要一致。15 条用例现在全红，先按这个现象查。

## 运行方式
```bash
python -m pytest tests -q
```
