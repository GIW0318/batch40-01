# GSB Bugfix Task
## 题面
宝箱保底改版后，玩家整理出一堆反例。重登之后保底计数回到零，之前垫的几十抽白费；不同品质的宝箱共用一个保底，开普通箱把限定箱的保底吃掉；保底触发后计数没有清零，下一箱又出稀有；十连被拆成十次单抽结算，保底只保住第一件；概率提升活动结束后仍按提升后的概率出；同一个宝箱因为网络重试被开了两次；保底计数按角色存，换小号又能重新垫；离线开箱和在线开箱结果不一致；保底触发那一刻服务器回滚，计数和物品一起没了；跨赛季继承规则写错，旧保底算进新池；开箱记录缺字段，客服没法复算。chest_pity_ledger.py 的 ChestPityLedger 要管 open、pity、reset 和 history。保底计数按账号、卡池、品质分开存，落库后再返回结果；十连按整批结算；概率提升有明确起止时间；开箱编号幂等；回滚要连同计数一起回滚；跨赛季按配置决定继承或清零；每次开箱写完整流水。保底计数以服务端为准，登录时先拉取再允许开箱；每次开箱记录使用的卡池版本和概率表；概率表版本切换要在开箱记录里能追溯；十连里每件物品单独编号，但保底判断按整批一次完成；保底计数变更和开箱结果同一事务落库。tests/test_chest_pity_ledger.py 的十五条检查眼下全红。

## 运行方式
```bash
python -m pytest tests -q
```
