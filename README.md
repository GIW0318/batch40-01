# GSB Bugfix Task
## 题面
办公网启用 IPv6 的第三周，整层楼的地址开始乱跳，默认网关也被改走。后来在弱电间找到一台被人插上去的家用路由器。源地址不是链路本地也接受路由通告；前缀的合法生存期小于首选生存期，仍然照原样下发；伪造的通告把路由器优先级调到最高，终端全部改网关；管理标志和其他标志跟 DHCPv6 配置矛盾，终端不知道去哪拿地址；防护只检查源 MAC，不检查接入端口策略；邻居通告冒充别人地址，地址冲突检测完全没发现；通告洪泛没有速率限制，交换机 CPU 被打满；前缀长度不是 64 也拿去做无状态自动配置；路由器生存期为零的通告仍被当成默认路由；同一台路由器发多个前缀，终端生成重复地址；通告被丢弃后旧前缀一直留在终端，没有失效通知；跳数限制不是 255 的通告也被接受。ipv6_ra_guard.py 的 RaPolicyGuard 要校验源地址必须是链路本地，合法生存期不能小于首选生存期，优先级变化要有策略，管理标志和 DHCPv6 配置要交叉检查，接入端口要有白名单，邻居通告和地址冲突检测要联动，通告按源做速率限制，只有 64 位前缀能用于自动配置，零生存期要触发前缀撤销，重复前缀去重，防护丢弃后要发失效通告，跳数限制必须是 255，每次判定给出可读原因。模块随附的十五项检查眼下全部报错。

## 运行方式
```bash
python -m pytest tests -q
```
