# GSB Bugfix Task
## 题面
我们把文件访问沙箱从自研路径检查换成了内核的 Landlock，结果限制范围比预期小得多：规则只加在目录上，目录里的符号链接指向外部时照样能读；文件和目录两条规则同时命中时，实现取了先加的那条；创建规则集时没有按内核支持的能力做掩码，内核不认识的权利被静默忽略，沙箱等于开口；程序执行子进程后规则没有按预期继承，子进程能访问全部路径；相对路径按调用时的工作目录解析，服务切了目录后规则指向别处；绑定挂载出来的别名路径绕过了规则；空规则集被当成不限制；拒绝规则加在允许规则后面，实现没有按优先级处理；超过路径长度上限的规则被截断后仍然生效；不同内核版本的能力号不一样，代码写死了新版本的值，老机器上直接失败。landlock_ruleset_fence.py 的 LandlockRulesetFence 要按内核实际能力协商权利集合，路径先做规范化和真实路径解析，目录规则向子树生效但符号链接要单独判定，规则冲突按最具体路径优先，创建和限制两个阶段分开，子进程继承要有验证，能力不支持时明确拒绝而不是降级放行，过长路径和空规则报错。仓库里十五条用例当前没有一条通过。

```bash
python -m pytest tests -q
```
