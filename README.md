# GSB Bugfix Task
## 题面
移动端接完 OIDC 登录后，渗透测试用一个自己签的 id_token 就换到了会话。查下来校验器的问题一串：算法字段写 none 也接受，写 HS256 时会把提供商的公钥当共享密钥用；密钥编号缺失时把 JWKS 里的密钥挨个试，试到能验过为止；发行方地址用前缀比较，多一个路径段也能过；受众是数组时只看第一个，多受众场景下没检查授权方，别的客户端签发给同一用户的令牌也能进；随机数没有和发起时的会话绑定，旧的 id_token 重放照样成功；签发时间在未来的令牌不拒绝；令牌哈希和代码哈希两个声明完全没验；密钥轮换后新的密钥编号不认识，实现不是去刷新 JWKS 而是直接放行；声明类型不做约束，字符串 false 被当成真；过期时间只在前端判断。oidc_idtoken_verify.py 的 OidcIdTokenVerify 要把签名、算法、密钥来源、发行方、受众、授权方、随机数、时间窗和令牌哈希逐项校验，只接受非对称算法并拒绝 none，密钥编号必须命中当前 JWKS 且缓存有上限和刷新策略，随机数一次性使用，任何声明缺失或类型不符都按失败处理，错误对外统一。仓库里十五条用例现在没有一条通过。

## 运行方式

```bash
python -m pytest tests -q
```
