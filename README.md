# GSB Bugfix Task
## 题面
举报邮箱里躺着一段视频，一件紫装在同一名商人手里被卖出去又买回来，来回六次，装备还在。卖店之后的回购页没有上限，往下翻几十页还能往回买；回购价按商人当前售价算，玩家低卖高买套走差价；一件物品卖了两次，两条记录都能回购；回购成功原记录没删，再点一次又出一件；所有商人共用一张回购列表，在甲城卖的东西跑去乙城能买回来；角色下线再上线，回购页清空，玩家以为东西丢了；名额满了以后最旧的记录不淘汰，新卖的反而挤不进去；绑定物品也能卖店再回购，转手就解绑；批量卖店只成功一半，回购记录缺了几条；商店刷新和回购并发，买回来的物品错位；金币不够时回购仍然扣款，余额变成负数。vendor_buyback_ledger.py 的 VendorBuybackLedger 管卖出、回购、过期和名额。每个商人独立维护固定名额，超出按最早卖出淘汰；回购价固定为卖出价；卖掉时生成唯一流水号，回购后立即失效；绑定物品拒绝卖店；批量操作要么全成要么全不成；扣款与发货同事务；下线保留记录，按过期时间清理。记录要存卖出时的物品快照，包括强化等级和附魔；回购时重新校验角色等级和背包空间；商人刷新只影响新上架商品；回购记录和卖出流水共用编号。tests/test_vendor_buyback_ledger.py 里那十五个断言，一个都没过。

## 运行方式
```bash
python -m pytest tests -q
```
