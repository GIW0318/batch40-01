# GSB Bugfix Task
## 题面
园区 DHCP 换新服务后，同一块网卡拿到两个地址，打印机和笔记本互相抢 IP，客服一天接了十几单。保留地址按 MAC 匹配时大小写和分隔符没归一，同一个网卡不算命中；地址池耗尽不会回收已过期租约，新终端一直拿不到地址；提供和请求之间两个客户端抢同一个地址，居然都收到确认；中继信息里的选项八十二没有回显，地址从错误的子网池分配；客户端请求无限租期也被接受，地址永久占住；拒绝续约后地址没有隔离，马上又发给下一个客户端；选项重载没有解析，附加选项被当成填充丢掉；客户端标识和 MAC 两种键混用，同一台机器被当成两台；续租从请求时间重新算，而不是从原到期时间延长；静态保留和动态池重叠，动态分配先抢走保留地址；广播标志没看，对还没配置地址的客户端单播回复；租约库没有落盘，重启后地址全部分发冲突。dhcp_lease_broker.py 的 DhcpLeaseBroker 要先把 MAC 归一成统一格式，过期租约定时回收，提供和确认之间做原子占位，选项八十二原样回显并参与子网选择，租期要有上下限，拒绝过的地址进入隔离期，正确解析选项重载，客户端标识和 MAC 统一成一种键，续租从原到期时间顺延，静态保留从动态池里排除，按广播标志选择回复方式，租约库持久化并能在重启后恢复一致状态。这十五条用例目前没有一条能过。

## 运行方式
```bash
python -m pytest tests -q
```
