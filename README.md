# GSB Bugfix Task
## 题面
共享盘换成网络文件系统后，权限判定和本地看到的不一样：访问控制列表里的掩码位没有参与有效权限计算，被掩码压掉的写权限仍然放行；新目录继承了默认访问控制列表，但创建文件时又把 umask 叠上去，实际权限比预期少；命名用户条目和所属组条目同时命中时，实现先看组再看用户；重复条目和顺序不对的列表被整份拒绝，其实应该先归一；符号链接上的访问控制列表没有跟随或拒绝，行为取决于底层；最小列表和扩展列表判断错，三个基本条目也被当成扩展；目录的进入权限没有和读权限分开检查；属主条目和掩码的交互算错，属主反而被掩码限制；chmod 改权限时把掩码写成了组权限，命名条目全部失效；递归设置时遇到符号链接直接跳过，链接目标权限没变。posix_acl_effective.py 的 PosixAclEffective 要按访问控制列表的判定顺序计算有效权限：属主、命名用户、所属组与补充组、其他，最后统一与掩码求交；默认列表只在创建时继承，umask 与默认列表同时存在时按规范处理；目录的进入权限单独检查；条目先归一再去重，顺序不影响结果；符号链接按策略处理；最小和扩展列表区分；结果给出每个主体的有效权限和命中的条目。仓库里十五条用例现在全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
