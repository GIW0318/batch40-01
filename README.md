# GSB Bugfix Task
## 题面
自研 MP4 封装接进短视频以后，首帧黑屏、口型偏移、时长还少一截。首帧显示时间是负的，没有写编辑列表，播放器从零开始播，开头黑几百毫秒。解码时间单调但显示时间会回退，封装器按显示时间排序写样本，顺序直接错。时间基用毫秒，长视频累积取整，一小时能漂出好几帧。三十二位时间戳在挂机一天后回绕，进度条跳回开头。音视频交错块切得太大，起播要等完整段，首屏很慢。字幕和章节轨道的时间基没转换，字幕整体错位。元数据 atom 顺序不合法，有些平台直接忽略封面。B 帧需要版本一的合成时间表，写成了版本零，帧序全乱。编辑列表只裁了音频的 priming，视频没裁，口型对不上。并行写样本表的时候 moov 里的偏移算错，部分播放器读到负位置。最后一个样本的时长没填，进度条少一段。封装器需要负时间戳有正确的编辑列表、解码与显示顺序分离、时间基换算不丢精度、三十二位回绕有处理、音视频裁剪一致、并行写 moov 有确定顺序，时长和索引也要能对上。15 条用例当前全部为红。

## 运行方式
```bash
python -m pytest tests -q
```
