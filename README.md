# GSB Bugfix Task
## 题面
大地图改成分块烘焙导航以后，NPC 跨区块就开始绕远或者卡墙。相邻 tile 高度差明明在步高以内，边缘却没有连上，路径在接缝处断掉。角色半径只在本 tile 内收缩，跨界通道窄了一半，胖怪过不去。斜坡角度按面法线算，两个 tile 的三角形法线略有差异，同一道坡一半能走一半不能。离线链接只在单侧 tile 注册，NPC 跳下去就回不来。动态障碍只在所在 tile 挖洞，跨界的石头漏挖，单位直接穿过去。异步烘焙完成顺序不固定，边界链接有时重复有时缺失。源几何更新了但 tile 版本号没变，旧导航数据一直残留。查询点正好落在接缝上时最近多边形选错，单位原地打转。大 tile 合并时顶点索引十六位溢出，远处区域整片错位。每次改动都全量重烘，运行时预算根本不够。多个线程同时写同一份导航数据没有锁，偶尔崩在寻路线程。导航烘焙得让跨 tile 边缘按高度和坡度正确缝合、角色半径在边界连续、离线链接双向注册、动态障碍跨块生效、版本号能驱动增量更新、索引宽度按规模选择。这 15 条用例眼下没一条能过，全部挂着红。

## 运行方式
```bash
python -m pytest tests -q
```
