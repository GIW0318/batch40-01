# GSB Bugfix Task
## 题面
CI 里给每个任务建用户命名空间，最近两次越权都和编号映射有关：两个映射区间重叠，内核接受了，容器里的普通用户落到了宿主上的另一个租户；容器里的零号用户直接映射到宿主零号，等于拿到了宿主机 root；只写了用户映射没写组映射，补充组全按宿主身份算；没有在写组映射前禁用 setgroups，进程可以自建组；不同用户的从属编号区间互相重叠，A 的容器能写到 B 的文件；newuidmap 辅助程序的参数没有校验，映射行数和单行范围都没有上限；下界加长度溢出三十二位后回绕成小数字；映射没有按起始编号排序，内核拒绝但错误信息被吞掉；空映射被当成默认映射；映射条数超过内核允许的行数时截断最后几行。userns_idmap_check.py 的 UsernsIdmapCheck 要在写入前校验整组映射：区间不得重叠且按起始编号排序，宿主零号默认拒绝，用户和组映射必须成对，写组映射前必须禁用 setgroups，从属编号要按用户隔离，辅助程序参数逐项校验，范围不得溢出，空映射报错，超过行数上限明确拒绝并指出多余项。仓库里那十五条用例没有一条能过。

## 运行方式
```bash
python -m pytest tests -q
```
