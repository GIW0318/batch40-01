# GSB Bugfix Task
## 题面
堡垒机接公司目录服务做权限判定，最近几次权限回收都不干净。组套组只展开了一层，祖父组的成员拿不到权限，曾祖父组反而漏判；两个组互相包含时递归没有上限，进程直接栈溢出；组的可分辨名称比较太死板，大小写、多余空格、转义写法不同就当成两个组；成员属性分页返回，代码只取了第一页，超过一千五百人的大组永远只认前一千五百个；目录返回的引用没有跟随策略，跨域组时有时无；组被改名或移动后，本地缓存还按旧名称命中；已删除的组仍然出现在缓存里继续授权；成员属性为空和属性不存在被当成同一种情况；服务端因为大小限制截断结果，客户端把它当成完整结果；不同组织单元下同名组被合并成一个。ldap_nested_group_fold.py 的 LdapNestedGroupFold 要把组关系展开成传递闭包：可分辨名称按规范归一后比较，嵌套深度和环要有上限，分页成员要全部取回，引用按白名单决定是否跟随，缓存带版本并在组变更时失效，删除组立即失去授权，截断结果要显式报错，同名不同路径的组分开保存。仓库里十五条用例现在全部报错。

## 运行方式
```bash
python -m pytest tests -q
```
