# GSB Bugfix Task
## 题面
潜行关卡加了三维音频遮挡以后，守卫的脚步声一会儿隔墙、一会儿贴脸。遮挡射线对每个声源每帧都打一次，同屏十几个声源就把音频线程预算吃满。只打一条中心射线，半堵墙挡住也算全遮挡，声音忽有忽无。门的开关状态没进遮挡判断，门关了脚步还是清清楚楚。上下楼层之间没有垂直遮挡，楼上的脚步像在耳边走。多普勒用的是上一帧的听者位置，快速转身时音高跳一下。距离衰减在不同区域混用线性和指数模型，跨过边界音量突变。混响区边界是硬切，走到门口或者跨两个区域时残响强度来回摆。声源和听者的更新频率不同，移动时声像左右抖。音频线程读听者状态没有快照，偶尔左右声道直接反了。声源超过最大距离仍然参与混音，白占 CPU。单声道声源做头部相关渲染时没补头部半径，定位总是偏后。同一帧里同时开门和移动声源时，遮挡值取到哪一版全看线程调度，声音会突然从墙后跳到面前。遮挡系统得按声源重要性分配射线预算、部分遮挡能有连续衰减、门窗和楼层状态参与判断、听者状态用一致快照、超出距离的声源真正退出混音。现有 15 条用例眼下清一色挂红。

## 运行方式
```bash
python -m pytest tests -q
```
