# GSB Bugfix Task
## 题面
夜城地图改成簇式前向光照以后，霓虹街区的灯就开始乱套。簇的深度切片按线性距离均分，近处一片特别厚、远处薄得可怜，脚边的小地灯经常整盏被吞掉；范围很大的广告牌点光只写进中心那一个簇，边缘像素完全没受光。灯光包围体和簇边界相交时，同一盏灯在两个簇里各累加一次，重叠带明显更亮。聚光用了外接球近似，锥体侧面漏出一圈光。阴影索引超过十六位之后高位被截掉，几盏灯共用同一张阴影图，影子互相串。CPU 构建网格时用的近远平面和 GPU 采样时的不一致，一推镜头整片光偏移。异步剔除任务上一帧的结果会覆盖当前帧，快速转身时灯突然全灭再亮。现在每帧把所有簇重建一遍，预算直接爆掉，GPU 经常等 CPU 提交。相机近平面从零点一改到零点零一，切片划分退化成一堆空簇。光源数到上限后多出来的灯不报错也不亮。主视图和反射相机共用同一套簇数据，水面里的灯光位置对不上。需要做到的是簇划分按非线性深度稳定切分、大范围光源覆盖所有相交簇且不重复累加、阴影索引不截断、异步结果带帧号校验，构建开销也要压在预算内。现有 15 条用例跑下来没有一条是绿的，全红。

## 运行方式
```bash
python -m pytest tests -q
```
