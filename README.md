# GSB Bugfix Task
## 题面
编辑器里换装和拖拽挂点最近老出问题。把一个武器从左手挂点拖到右手挂点，代码只改了父节点指针，没有补偿局部变换，枪直接飞到地图外面。脏标记只往下传一层，孙节点的世界矩阵不更新，护甲穿在角色身上却停在原地。兄弟节点的顺序一变，同一帧的遍历顺序就不同，静态合批的结果每次都不一样。父节点被隐藏以后，子节点仍然参与包围盒计算，相机对着空气裁剪。实例覆写变换和原型变换被乘了两次，换装后肩甲偏移一大截。负缩放没有翻转法线，镜像出来的角色背面发黑。序列化按哈希表顺序写父子关系，回读之后层级整个打乱。遍历过程中动画系统增删子节点，迭代器失效，有些节点整帧没更新。浮动原点偏移以后，离原点很远的载具开始精度抖动。暂停时仍然每帧重算全场景矩阵，预算白白浪费。动画线程写 transform、渲染线程读，中间没有快照，偶尔看到角色瞬间拉伸。这几处得一起修：重挂父节点能保持世界位置、脏标记沿整棵子树传播、遍历和序列化顺序稳定、负缩放和浮动原点有正确退化，暂停时不做无意义重算。那 15 条用例现在没有一条能过，全部失败，全红。

## 运行方式
```bash
python -m pytest tests -q
```
