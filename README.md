# GSB Bugfix Task
## 题面
野外精英怪的掉落归属改版后，抢怪纠纷翻了几倍。最后一击的玩家和伤害最高的玩家不是同一个人，掉落却给了最后一击；保护期内别的玩家仍然能捡，捡完还嘲讽原队伍；怪物尸体先消失，掉落物还浮在空中，或者尸体还在但东西没了；跨阵营玩家能直接拾取；归属按队伍算，队长退队后整队失去拾取权；同一件掉落被两个客户端同时拾取，复制出两份；保护期倒计时读的是客户端时间，改系统时间就能提前捡；怪物被抢后原队伍失去拾取权，伤害统计却还算他们的；掉落物掉进地形下面，既捡不到也不回收；服务器重启后保护期重置，早就过期的掉落又活了；拾取记录重复上报，任务计数翻倍。worlddrop_claim_window.py 的 WorlddropClaimWindow 负责 register_kill、claim、expire 和 rights。归属按有效伤害和最后一击共同判定，规则写死；保护期以服务器时间为准；尸体和掉落物生命周期绑定；跨阵营默认不可拾取；队伍解散后归属转到仍在场的成员；拾取按掉落编号加锁，只能成功一次；重启后从持久化记录恢复剩余保护期。拾取模式和保护期分别校验，自由拾取也要遵守归属时间；掉落物要记录生成帧和过期帧；跨地图传送后归属不转移，除非原队伍全部离开；尸体消失前要先把未拾取物品结算进邮件。tests/test_worlddrop_claim_window.py 的十五条断言现在全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
