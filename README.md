# GSB Bugfix Task
## 题面
插件沙箱换成 WebAssembly 之后，一个第三方插件读到了宿主环境变量。导入白名单只校验了模块名，没看字段名，同一个模块里的危险函数一起被放进来；启动函数在资源上限生效之前就执行，插件在初始化阶段把内存吃到上限；内存声明的最大页数超过宿主限制也接受，增长指令没有检查返回值；函数表的下标越界时落到了相邻函数；文件预打开路径没有做真实路径解析，上跳路径跑出了沙箱目录；模块声明了多块内存，实现只限制了第一块；间接调用没有做类型检查，用错签名调用宿主函数；指令预算只在函数入口扣减，循环里永远不扣；宿主函数返回的指针没有校验范围，插件能读宿主内存；导入项从依赖模块里间接解析，白名单只查了顶层。wasm_import_allowlist.py 的 WasmImportAllowlist 要在实例化前完成校验：导入按模块加字段两级白名单，启动函数在限制生效后运行，内存页数、表大小、实例数都有上限，越界访问和类型不匹配直接陷入，预打开路径真实解析并限制在根内，多内存逐个限制，指令预算按基本块扣减，宿主返回的指针做范围检查，间接导入也要递归校验。仓库里十五条用例全部失败。

## 运行方式
```bash
python -m pytest tests -q
```
